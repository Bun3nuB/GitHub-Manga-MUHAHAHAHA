## Ep.5 ReStart

หลังจากน้องจิ้งจอกได้รับพลังแห่งโลกคู่ขนาน หรือ ที่ถูกเรียกกันว่า Git ที่สามารถควบคุมเวลา เส้นทาง และการดำรงอยู่ของจักรวาลได้

น้องจิ้งจอกรู้ทันทีว่า หากอยากใช้มันให้ได้ผลจริง เขาต้องฝึกฝนอย่างหนัก

น้องจิ้งจอกจึงได้เรียนรู้ วิชา Git Add/Commit เป็นความสามารถที่ทำให้เขาสามารถ บันทึกช่วงเวลาสำคัญ (Checkpoint) ของแต่ละจักรวาลไว้ได้ทุกเมื่อที่ต้องการ แม้จะเกิดอะไรขึ้นเขาก็สามารถย้อนกลับไปแก้ไขหรือหนีไปอีกโลกได้ตลอด

และอีกวิชาที่ทรงพลังไม่แพ้กัน น้องจิ้งจอกได้ รังสรรค์วิชาที่มีชื่อว่า Branch ซึ่งสามารถพาไปหรือสร้างโลกคู่ขนานต่างๆได้ เขาสามารถสร้างโลกใหม่เพื่อทดลองแนวทางที่แตกต่าง โดยไม่ทำลายเส้นเวลาหลักได้ และเมื่อเขาต้องการกลับมายังเส้นทางเดิม เขาก็แค่...

"git checkout..."

เมื่อน้องจิ้งจอกรวมพลังของทั้งสองวิชา น้องจิ้งจอกก็จะสามารถ บันทึกช่วงเวลาสำคัญ และ ท่องระหว่างโลกคู่ขนาน ได้อย่างอิสระ เพื่อค้นหาเส้นทางที่สามารถเปลี่ยนแปลงอนาคตได้ ด้วยสายตาที่มุ่งมั่น และเสียงหัวใจที่ยังไม่ยอมแพ้

"ด้วยพลังนี้ฉันจะกลับไปช่วยบอสให้ได้!!"

น้องจิ้งจอกตะโกนออกมาด้วยความโกรธและความหวัง ที่เขาจะสามารถแก้ไขทุกอย่างที่เคยเละเทะให้กลับมาอย่างที่เคยเป็น

" ทะ..ทะ..ทำไมกัน ทำไมถึงย้อนกลับไปไม่ได้ละ! มันต้องมีทางสิ!!"

แต่แล้วน้องจิ้งจอกก็ได้รู้ว่า พลังที่สุดแสนจะโกงของเขานั้น ยังมีจุดอ่อนนึงอยู่

"บ้าเอ้ยยย!! ทั้งทั้งที่คิดว่าจะได้ช่วยให้คุณรอดบอส... ผะ..ผมมันไม่ได้เรื่องเลย ทั้งหัวอ่อน เชื่ออะไรโดยไม่คิด และตอนที่อุตสาห์ได้พลังสุดโกงมาก็ยังช่วยคุณไม่ได้!!"

จุดอ่อนนั้นคือ ถ้าน้องจิ้งจอกอยากCheckout หรือ ย้อนกลับไปจุดไหน น้องจิ้งจอกก็ต้อง Commit จุดนั้นก่อน แต่ตอนที่บอสตายไป น้องจิ้งจอกยังไม่ได้รับพลังมันทำให้เขานั้นโกรธแค้นและสิ้นหวัง

แต่แล้วน้องจิ้งจอกก็ผุดไอเดียนึงขึ้นมา

"ฉันช่วยบอสด้วยพลังนี้ไม่ได้ แต่ฉันสามารถช่วยล้างแค้นให้บอสด้วยพลังนี้ได้!!"

น้องจิ้งจอกได้ตั้งเป้าที่จะล้างแค้นให้บอสโดยเขานั้น ก็เริ่มจากCommitจุดที่เขาอยู่

"git commit -m 'Checkpoint Alpha'"

และเริ่มออกตามล่าสมาชิกแก๊งมาเฟียที่ละคน

**บทส่งท้าย:**

น้องจิ้งจอกได้เริ่มการล้างบางแก๊งมาเฟียในโลกต่างๆ แต่ความแค้นของเขาก็ดูจะไม่ลดละลงเลย...
