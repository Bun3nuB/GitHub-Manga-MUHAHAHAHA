## Ep.6 Realize

หลังจากฝึกฝนพลังของ Git จนชำนาญแล้ว น้องจิ้งจอกก็พร้อมที่จะแก้แค้นให้กับเจ้านายผู้เคารพรัก

"git commit -m 'Checkpoint Alpha'"

แสงสีเงินวาบขึ้น เขาได้สร้าง checkpoint แรกไว้แล้ว น้องจิ้งจอกออกตามล่าแก็งมาเฟียด้วยพลังใหม่ของเขา การต่อสู้ครั้งแรกเขาแทบตาย แต่...

"git checkout Checkpoint_Alpha"

เขากลับมายังจุดเริ่มต้น พร้อมความทรงจำเกี่ยวกับวิธีการต่อสู้ของศัตรู การต่อสู้ครั้งที่สอง เขาทำได้ดีขึ้น แต่ยังไม่ชนะ

"git checkout Checkpoint_Alpha"

การต่อสู้ครั้งที่สาม เขาชนะหัวหน้าแก็งคนแรกได้

"git commit -m 'First gang leader defeated'"

การต่อสู้ครั้งที่สี่ เขาชนะได้สองคน แต่ตายจากมือคนที่สาม

"git checkout Checkpoint_Alpha"

วนไปเรื่อยๆ... หลังจากผ่านไปหลายร้อยครั้ง น้องจิ้งจอกสามารถฆ่าแก็งมาเฟียทั้งหมดได้สำเร็จ แต่แล้ว... เมื่อแก็งมาเฟียตายหมด น้องจิ้งจอกกลับไม่รู้สึกดีใจหรือเติมเต็ม เขารู้สึกโควงเคว้งและว่างเปล่า

"ทำไม... ทำไมฉันไม่รู้สึกโล่งใจเลย?"

เขาพึมพำ มองดูซากศพของศัตรู น้องจิ้งจอกคิดว่าเป็นเพราะพวกแก็งมาเฟียยังไม่ได้รับโทษที่ควรรับ การตายครั้งเดียวนั้นง่ายเกินไป

"git checkout Checkpoint_Alpha"

ครั้งนี้เขาไม่ได้ฆ่าพวกมันให้ตายง่ายๆ เขาทรมาณพวกมันก่อน ตัดนิ้ว ตัดมือ ให้พวกมันทุกข์ทรมานก่อนตาย แต่หลังจากนั้น ความรู้สึกว่างเปล่ายังคงอยู่

"git checkout Checkpoint_Alpha"

ครั้งนี้เขาทรมาณพวกมันให้นานขึ้น ให้พวกมันขอร้องความตาย

"git checkout Checkpoint_Alpha"

"git checkout Checkpoint_Alpha"

"git checkout Checkpoint_Alpha"

โลกแล้วโลกเหล่า แก็งมาเฟียถูกฆ่า ถูกทรมาณ ถูกย้อนกลับมา แล้วถูกฆ่าอีก น้องจิ้งจอกเริ่มลืมไปแล้วว่าเขาได้ทำแบบนี้ไปกี่โลกแล้ว กี่ร้อย กี่พัน หรือกี่หมื่นครั้ง...

จนวันหนึ่ง เขาหยุดมองรอบข้างทุกโลกที่เขาได้ต่อสู้กับแก็งมาเฟีย ทุกที่ที่เขาไป กลายเป็นทะเลเพลิง มีคนบริสุทธิ์ตายมากมาย เด็กกำพร้าเหมือนตัวเขาเอง คนขับแท็กซี่ที่ไม่มีส่วนเกี่ยวข้อง พนักงานร้านข้างๆ ที่เพิ่งเริ่มทำงาน ทั้งหมดตายเพราะความแก้แค้นของเขา

"นี่... นี่คือสิ่งที่บอสอยากให้ฉันทำเหรอ?"

น้องจิ้งจอกถามตัวเอง เขานึกถึงใบหน้าอ่อนโยนของเจ้านายในช่วงสุดท้าย ก่อนที่จะถูกฆ่า ไม่ใช่... สิ่งที่เจ้านายอยากให้เขาทำไม่ใช่การแก้แค้น แต่มันคือการช่วยเหลือคนอื่น เหมือนที่เจ้านายเคยช่วยเหลือเขา

เจ้านายของเขาไม่เคยเป็นหัวหน้าองค์กรอาชญากรรม เจ้านายของเขาเป็นหัวหน้าขององค์กรเทียร์เทอร์ ที่ช่วยเหลือเด็กกำพร้าและคนยากจน แก็งมาเฟียฆ่าเจ้านายเพราะกลัวว่าการทำความดีจะขัดขวางธุรกิจสกปรกของพวกมัน

"ฉัน... ฉันเข้าใจผิดมาตลอด"

น้องจิ้งจอกน้ำตาไหล เขาใช้ git log --all ดูประวัติทั้งหมดที่เขาได้ทำ หลายพันโลกของการฆ่า การทรมาณ การทำลาย

"ฉันกลายเป็นปีศาจไปแล้ว..."

"git checkout..."

น้องจิ้งจอกใช้ Git เป็นครั้งสุดท้าย กลับไปยังจุดเริ่มต้น จุดที่เขาเพิ่งได้พลังนี้มา ครั้งนี้เขาไม่ได้ออกไปแก้แค้น แต่เขาไปหาเด็กกำพร้าคนอื่นๆ ที่เคยอยู่ภายใต้การดูแลของเจ้านาย เขาไปหาคนยากจนที่เจ้านายเคยช่วยเหลือ เขาใช้พลังของ Git ไม่ใช่เพื่อแก้แค้น แต่เพื่อช่วยเหลือคนอื่น

ใช้ git branch สร้างโลกคู่ขนานที่คนยากจนมีชีวิตที่ดีขึ้น

ใช้ git commit เซฟช่วงเวลาแห่งความสุขให้กับเด็กๆ

ใช้ git merge รวมความดีจากหลายโลกเข้าด้วยกัน

น้องจิ้งจอกได้กลายเป็นหัวหน้าขององค์กรการกุศลคนต่อไป เขาสืบทอดเจตนารมณ์ของเจ้านาย เพื่อช่วยเหลือเด็กแบบเขาต่อไป ในคืนแรกที่เขาช่วยเหลือเด็กกำพร้าคนแรก

น้องจิ้งจอกรู้สึกได้ถึงความเติมเต็มที่แท้จริง นี่แหละคือสิ่งที่เจ้านายอยากให้เขาทำ ไม่ใช่การแก้แค้น แต่เป็นการสืบทอดความดี
