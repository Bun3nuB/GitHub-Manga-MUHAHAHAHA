## Ep.5 Learning-And-Realize

หลังจากน้องจิ้งจอกได้รับพลังแห่งโลกคู่ขนาน หรือ ที่ถูกเรียกกันว่า Git นั้น น้องจิ้งจอกก็ต้องเรียนรู้การใช้พลังนี้ให้ชำนาญให้ได้

น้องจิ้งจอกจึงได้เรียนรู้ วิชา Add/Commit เป็นความสามารถที่ทำให้น้องจิ้งจอกสามารถ SaveจุดCheckpointและสามารถย้อนกลับมาได้
และอีกวิชาที่ทรงพลังไม่แพ้กัน น้องจิ้งจอกได้ รังสรรค์วิชาที่มีชื่อว่า Branch ซึ่งสามารถพาไปหรือสร้างโลกคู่ขนานต่างๆได้

เมื่อน้องจิ้งจอกนำพลังทั้งสองมาใช้ร่วมกันน้องจิ้งจอกก็จะสามารถSave Checkpointในโลกคู่ขนานต่างๆหรือโลกที่น้องสร้างขึ้นมาเองได้ เพื่อคนหาวิธีหรือโลกที่น้องจิ้งจอกต้องการ

"ด้วยพลังนี้ฉันจะกลับไปช่วยบอสให้ได้!!"

น้องจิ้งจอกตะโกนออกมาด้วยความโกรธและความหวัง ที่เขาจะสามารถแก้ไขทุกอย่างที่เคยเละเทะให้กลับมาอย่างที่เคยเป็น

" ทะ..ทะ..ทำไมกัน ทำไมถึงย้อนกลับไปไม่ได้ละ! มันต้องมีทางสิ!!"

แต่แล้วน้องจิ้งจอกก็ได้รู้ว่า พลังที่สุดแสนจะโกงของเขานั้น ยังมีจุดอ่อนนึงอยู่

"บ้าเอ้ยยย!! ทั้งทั้งที่คิดว่าจะได้ช่วยให้คุณรอดบอส... ผะ..ผมมันไม่ได้เรื่องเลย ทั้งหัวอ่อน เชื่ออะไรโดยไม่คิด และตอนที่อุตสาห์ได้พลังสุดโกงมาก็ยังช่วยคุณไม่ได้!!"

จุดอ่อนนั้นคือ อยากน้องจิ้งจอกอยากCheckout หรือ ย้อนกลับไปจุดไหน น้องจิ้งจอกก็ต้อง Commit จุดนั้นก่อน แต่ตอนที่บอสตายไป น้องจิ้งจอกยังไม่ได้รับพลังมันทำให้เขานั้นโกรธแค้นและสิ้นหวัง

แต่แล้วน้องจิ้งจอกก็ผุดไอเดียนึงขึ้นมา

"ฉันช่วยบอสด้วยพลังนี้ไม่ได้ แต่ฉันสามารถช่วยล้างแค้นให้บอสด้วยพลังนี้ได้!!"

น้องจิ้งจอกได้ตั้งเป้าที่จะล้างแค้นให้บอสโดยเขานั้น ก็เริ่มจากCommitจุดที่เขาอยู่และเริ่มออกตามล่าสมาชิกแก๊งมาเฟียที่ละคน

**บทส่งท้าย:**

น้องจิ้งจอกได้เริ่มการล้างบางแก๊งมาเฟียในโลกต่างๆ แต่ความแค้นของเขาก็ดูจะไม่ลดละลงเลย...
